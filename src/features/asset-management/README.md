# 🏗️ asset-management (Gestão de Ativos Corporativos e Infraestrutura)

Aqui ficam as features focadas na estrutura física, engenharia e manutenção pesada do patrimônio.

facilities: O painel central/visão macro de controle predial.projetos-obras: Lógica de reformas, medições, cronogramas e plantas.

manutencao: Ordens de serviço para consertos, elétrica, hidráulica e ar-condicionado.

limpeza-reservatorios: Embora pareça limpeza comum, por envolver normas técnicas específicas, paradas programadas de abastecimento e laudos de potabilidade, entra na engenharia/infraestrutura como manutenção predial crítica.
